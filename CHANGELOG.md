# Changelog — MindFlow Max

- Hardened Cloudflare sync endpoint: key validation, JSON content type checks, payload size limit, KV configuration errors and no-store responses.
- Added cloud restore flow alongside cloud upload.
- Added import normalization, file size guard, and confirmation before replacing local data.
- Improved mobile safe-area handling, focus-visible styles, dark header styling and reduced-motion support.
- Updated PWA manifest/icon and scoped service-worker cache cleanup to MindFlow caches only.
- Added deployment, privacy, and Cloudflare KV setup documentation.
