Hướng Dẫn Triển Khai Cloudflare Pages (Production-Ready)

Gói triển khai đầy đủ đã được đóng gói sẵn gồm public/, functions/api/sync.js, _headers, _redirects và wrangler.toml.

# Cách 1: Triển khai trực tiếp qua Wrangler CLI (10 giây)

unzip mindflow-cloudflare-pages.zip -d mindflow-app

cd mindflow-app

npx wrangler pages deploy public --project-name=mindflow-self-help

⚡ Cách 2: Kết nối Git (CI/CD tự động)

1. Đẩy thư mục lên GitHub / GitLab.

2. Vào Cloudflare Dashboard → Workers & Pages → Create → Pages.

3. Chọn nhánh main, đặt Build output directory là public (Build command để trống).

🔒 Bảo mật & PWA Chuẩn Production

• _headers: Đã cấu hình HSTS, X-Frame-Options, X-Content-Type-Options, Referrer-Policy & Cache-Control.

• PWA Offline: Tích hợp manifest.json & sw.js cài đặt được lên màn hình chính iOS/Android.
